# Посты в ТГ-канал

## Воронка и фазы
- Предпрогрев (боль, без продукта) → Прогрев (переворот + доказательство + мягкий тизер) → Продажа (анонс → открытие записи → дожим).
- Один пост - один смысл.
- Продукт (интенсив/курс) не называть до фазы продажи. Первый намёк - ближе к открытию записи.
- Каждый день петлёй уводит к продукту; решение не отдавать бесплатно целиком (обнажать боль, метод придерживать).

## РАЗНЫЕ конструкции (главное - не по одному скелету)
Чередовать типы постов, чтобы лента не читалась по колее:
- провокация / голый тезис
- личная история / признание
- кейс ученицы (третье лицо, без имён)
- разбор
- самодиагностика (каскад вопросов к себе)
- мифбастер (короткий, в 2-4 строки)
- заход с прямой речи клиента
- заход с цифры/числа
- видение будущего (точка Б)
- сухой анонс / дожим

Запреты на повтор:
- Не гонять из поста в пост «Дело не в X, а в Y» - только там, где реально уместно.
- Разводить концовки: не только «🔥, если...», а вопрос в комменты, инструкция, приземление на сцену, ссылка.
- Объём постов - от задачи дня (1-4 в день), не фиксировать.

## Голос и факты
- Голос эксперта (см. правила сторителлинга): через свой опыт, разговорно, «Смотрите/Знаете/Друзья».
- Без длинного тире «—», только «-».
- Только реальные смыслы эксперта. Не выдумывать истории, цифры, спрос («вы давно просили» - только если правда просили).
- Кейсы учениц - третьим лицом, без имён.

## Механика продажи (фаза продажи)
- Лесенка цен и дефицит: ранний доступ (напр. 990, часто 1 день) → второе окно дороже → закрытие вечером перед стартом. Во время продукта продаж нет.
- Дожим в последний день: «кто откладывает - через год будет там же».

## Петля и источники тем
- Перелинковка с инстаграм в обе стороны: пост в канале уводит на сторис/рилс и наоборот.
- Комментарии - тёплый источник тем: отвечать на возражения, а сильные возражения превращать в отдельные посты.

## Формат вывода
- Полные тексты постов, по дням, в порядке публикации (копируемый .txt).
- Либо контент-план-таблица: дата, день, фаза, тип поста, заголовок, основная мысль, ВИСП, СТА.

## Финальная проверка
- Реально ли прогревает к продукту (петля к продукту каждый день), а не просто «хороший контент».
- Конструкции и концовки разные, не по шаблону.
- Факты реальные, голос её, без длинного тире.
