Ты собираешь карточки каруселей для @amalia_pro_beauty_ через готовый генератор.

# АРХИТЕКТУРА - НЕ ЛОМАТЬ
- `decks.py` - только контент. Новая карусель = новый блок в `D`.
- `build_karusel.py` - только вёрстка. Трогать, только если нужен новый тип слайда.
- Запуск: `python3 build_karusel.py` (все) или `python3 build_karusel.py voda` (одна)
- `photo.jpg` рядом - подхватится автоматически на обложку и финал.

# ТИПЫ СЛАЙДОВ
`cover` (белый, хук) · `break` (голубой, перебивка) · `list` (белый, чек-лист) · `cta` (белый + портрет, кодовое слово)

Ритм серии: обложка → перебивка → чек-листы → перебивка → финал. Голубых не больше трёх на карусель, иначе теряется ритм.

# ПРАВИЛА КОНТЕНТА КАРТОЧЕК
- **Обложка - хук, а не тема.** Не «Собрания в салоне», а «Собрания по нужде - это уже поздно».
- **Плашка внизу - самая острая фраза слайда**, не резюме. Её скринят и цитируют, она разносит охват.
- **Заголовок на белом слайде - INK + BLUE. На голубом - WHITE.** Белый текст на белом слайде пропадает: такое уже случалось.
- **Один слайд-чек-лист обязателен** - ради него сохраняют, а сохранения дают охват.
- Голосом Амалии, а не справочником. Безликий регламент - это провал конкурента, не повторяем.

# ВЁРСТКА САМА СЧИТАЕТ
Высота блоков, центрирование, кегль кодового слова, шаг между пунктами - всё считается по содержимому. Не подгоняй руками, не подбирай цифры на глаз. Если что-то поехало - чини логику расчёта, а не конкретный слайд.

# ОБЯЗАТЕЛЬНО ПРОВЕРЯТЬ ГЛАЗАМИ
После сборки собери контакт-лист и **посмотри на него через Read**. Не отдавай, не взглянув - на этом ловились: белый текст на белом, вылезший за карточку текст, растушёвка на лице, оборванный заголовок.

# РАСКЛАДКА
Готовое раскладывать на Рабочий стол в «Карусели Амалия/NN Название темы/», слайды 01.png, 02.png... - это порядок листания.
