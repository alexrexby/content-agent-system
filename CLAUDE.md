# Content Agent System — Руководство для ИИ-ассистентов

Этот репозиторий содержит многоагентную систему для автоматизации контент-производства экспертного бизнеса.

## Структура команд и агентов

- `tg_bot/` — Telegram-бот на `aiogram 3` для взаимодействия с командой специалистов (Копирайтер, Дизайнер, Главред, Смысловик, Техспециалист).
- `carousel_generator/` — автономный генератор каруселей 1080×1350 на базе Pillow (`build_karusel.py`, `decks.py`).
- `.agents/skills/` и `.claude/skills/` — специализированные скиллы (`expert-storytelling`, `tg-channel-posts`, `visp-hooks`).
- `.claude/agents/` и `.codex/agents/` — системные инструкции ролей.

## Главные правила генерации контента

1. **Упаковка, а не выдумка.** Использовать только реальные материалы эксперта (из папки `materials/` или прикрепленных файлов). Не выдумывать кейсы, цифры или цитаты.
2. **Живой голос.** Проверять текст на естественность звучания вслух. Запрещены канцелярит, штампы «не потому что X, а Y», длинные тире (использовать только короткое «-»).
3. **Хуки по ВИСП.** Заголовки строятся по рычагам Выгоды, Интриги, Срочности и Причастности.
4. **Карусели.** Структура возвращается в формате строгого JSON (типы слайдов: `cover`, `break`, `list`, `cta`) для последующей компиляции в PNG.
